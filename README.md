3. **מערכת-אמת**: כל מה שיש בגיט שצריך להיות פרונט — הופך כאן לאפליקציה חיה אמיתית (לא דף-מפוזר, לא דף-משעמם). ניהול-הבעלים מכאן, **מפתח-המפעיל: headcorner — "זאתי שפותחת את הכל"**.

5. **קדמיות-המטבע**: הדגשת מטבעות-גדולים ורשתות-מוכרות (BTC·ETH·SOL·USDT ודומיהן) — **לא** להדגיש steem/hive/blurt בפרונט; הם נשארים שכבת-עגין-ראיות בלבד (DECISIONS #39).
