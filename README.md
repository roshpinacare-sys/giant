```bash
bun install

```

## נתיבי-אמת (ריבונות-נתיבים · גל-7)

ברירת-המחדל קוראת מבנה-estate מקומי. כדי-להצביע-על-clone-של Domain בכל-מקום:

```bash
SAOS_ESTATE_DIR=/path/to/estate bun run dev
```

- `SAOS_ESTATE_DIR/Domain/dex/state.json` · `giants.json` · `honest-econ.json` · `truth/latest.json` — עוגני-האמת-הכלכלית.
- **בלי-הקבצים האלה המערכת לא ממציאה**: כל-ה-APIs מידרגים בכנה (fail-honest מדוד — "לא נמדד").
- מטמוני-מדידה: `db/` (cwd-יחסי) — `market-cache.json` · `trust-cache.json` (saos-trust-check@0.1.0).

## הכללים (בלי-חריגה)

1. **אפס-סימולציות** — כל-מספר מ-API/קובץ-אמת; כשל = `—` או "לא נמדד", אף-מספר-מזויף.
2. **יחידות-אמת** — 1 = 1000µ (קנון-גל-42); מציגים יחידות-אנוש בלבד.
3. **חוקי-עיצוב גל-6** — `g-card` · `g-view-in` · `g-scroll` · `Recipe` לכל-פאנל-חדש (docs/design/design-laws.md).
4. **מפת-החיבור** — `src/lib/giant/empire-map.ts` היא הקנון: כל-ספר-חדש-באימפריה נרשם בה עם-ראיה.
5. **הערוץ-האחד** — הוראות-הבעלים בפרוטוקול saos-owner-channel (roots sha256) בלבד.
